# TensorFold Manager v0.1.0-alpha.2

## 简体中文

- 管理界面新增 **简体中文 / English** 切换，覆盖 17 个页面、导航、表单、操作提示和确认信息。
- macOS 菜单及 App 自有对话框同步切换语言。偏好保存在 App 中，重启后仍保持。
- 切换语言保留未保存的表单输入；模型名称、路径、原始日志和聊天内容保持原文。
- GitHub 新增 [英文说明](https://github.com/alickfine/TensorFold-Manager/blob/main/README.en.md)及英文验收记录，中文首页可直接切换。

下载下方 Apple Silicon DMG，打开并将 App 拖入“应用程序”。模型与主引擎不包含在安装包中，首次安装需要联网。现有模型目录可继续扫描使用。

## English

- Added a **简体中文 / English** language switch across all 17 workspace sections, navigation, forms, action messages and confirmations.
- macOS menus and App-owned dialogs follow the selected language. The preference survives App restarts.
- Switching preserves unsaved form inputs. Model identifiers, paths, raw logs and user conversations remain in their original form.
- Added an [English README](https://github.com/alickfine/TensorFold-Manager/blob/main/README.en.md) and English acceptance record, linked from the Chinese project homepage.

Download the Apple Silicon DMG below, open it and drag the App into Applications. Models and the main engine are installed separately; initial installation needs internet access. Existing model directories can still be scanned.
