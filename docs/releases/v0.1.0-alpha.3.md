# TensorFold Manager v0.1.0-alpha.3

## 简体中文

本版按实际使用反馈精简工作台，并修复模型检测、更新和聊天的失败路径。

- 12 个主菜单；移除重复标题行、独立模型配置、量化上传、参考答案测试和功能适配菜单。模型配置改为模型库弹窗；API 端口、认证与密钥集中管理。
- 启动列表依据当前引擎实际 MLX 检测结果；模型或引擎发生变化时重新检测，避免旧结果误用。统计最多两位小数，缓存展示真实采样与未采集状态。
- 支持目录内选模型后直接下载，可选择 Hugging Face 或国内第三方镜像；未核实的 ModelScope 映射不提供入口。
- 本地磁盘模型发现与目录自动登记；排除网络卷、应用包及私密应用目录，扫描限制和权限缺口明确显示部分结果。
- 引擎配置精简，日志过滤栏紧凑，基准预设简化，聊天改为消息列表与底部输入；修复重复提交、配置继承和错误后不可重试的问题。
- 手动升级贯通候选安装、停机前兼容检查、激活与真实 API 验证。失败恢复原模型及实际运行参数，保留待应用编辑；原子切换期间不可取消，外部服务会阻断升级。
- 健康采样超时可以恢复；辅助模型刷新失败不会将已成功的下载或升级错误地标为失败。

**发行边界：** Apple Silicon / macOS 14+ 测试版。Ad hoc 签名，未 Apple Developer ID 签名或公证。首次引擎安装和模型下载需要联网；新版本完整大模型下载及真实 GLM 升级不作为本轮已完成的业务验收。详情见验收记录。

## English

This release simplifies the workspace and fixes failure paths reported during use.

- 12 main sections; redundant header and separate configuration, quantization/upload, reference-test and capability menus removed. Model settings open in the library dialog; API ports and authentication share one page.
- Launch choices use current-engine MLX detection, rechecked when engine/model identity changes. Metrics use at most two decimals; cache values retain real sampling and unavailable states.
- Download catalog checkpoints directly from Hugging Face or the third-party mirror. Unverified ModelScope mappings are not offered.
- Discover local-disk models and register directories. Network mounts, app packages and private app directories are excluded; limits and permission gaps produce explicit partial results.
- Smaller engine settings and log controls, benchmark presets, message-list chat with bottom composer. Duplicate submissions, inherited settings and retry after errors are repaired.
- Manual upgrades install candidates, check compatibility before stopping, activate and verify a real API request. Failure restores the original model/running parameters while preserving pending edits. Atomic switches reject cancellation; external services block upgrades.
- Health sampling recovers after transient timeouts. Auxiliary refresh failures no longer turn successful downloads/upgrades into failed transactions.

**Distribution:** Apple Silicon, macOS 14+, alpha. Ad hoc signed; no Developer ID signature or Apple notarization. Initial engine/model downloads require internet access. Full large-model downloads and a live GLM upgrade are not claimed as completed acceptance in this pass. See the acceptance record.
